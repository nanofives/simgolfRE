## Purpose
Picks the landmark type a donating golfer unlocks, records it in the two landmark bitmasks and appends the "now available" notice to the shared text buffer. The search starts at golfer `g`'s world position, the dwords 0x005794b8 + g*0x100 and 0x005794bc + g*0x100 read at 0x004722ca and 0x004722d0 and shifted right by 10 (0x004722d6, 0x004722d9) into tile coordinates; the tile index is x*50 + y (0x004722de..0x004722e4) and the tile's type byte is 0x005722e8 + index (0x004722e7). A tile is accepted when the byte at 0x00578376 + type*0x30 is 4 (0x004722f6, `jne` 0x004722fc), the type is not 0x16 (0x004722fe, `je` 0x00472301) and the word at 0x0053caf0 + index*2 has no bit of 0x320 set (0x00472303..0x00472314). Otherwise x and y each move by Random::range(3) - 1 (0x0045c1e0 called with ecx = 0x00822d9c at 0x0047231d and 0x00472332, each result masked to 16 bits at 0x00472322 / 0x00472337) and the test restarts, unless tileBlocked 0x0040bf60 reports the new tile blocked (0x00472342, `jne` 0x0047234c), in which case the function returns having changed nothing but the RNG seed. Once a tile is accepted the landmark id comes from the first byte of row `who` of the 50-byte-row table 0x0053a454 (0x0047235e): the byte minus 0x41 (0x00472366) indexes the switch at 0x0047236c, whose byte table 0x004724a8 and dword table 0x0047247c encode A -> 0x16a, C -> 0x168, F -> 0x170, G -> 0x16f, H -> 0x16d, L -> 0x16c, M -> 0x16b, P -> 0x169, R -> 0x170, S -> 0x173, X -> 0x171, and send every other byte to the default at 0x004723c3, which takes Random::range(10) masked to 16 bits plus 0x168. Bit (id - 0x168) is then set in both 0x00822c70 (0x00472400) and 0x00543cfc (0x0047240b), the string at 0x004e409c is appended to the buffer (0x00472411), landmarkName 0x004074a0 is called with (id - 0x168, 1) at 0x00472434, the string at 0x004e4070 is appended (0x00472445) and startMessage 0x0040cb00 is called with (0x80000210, 0, -1) at 0x0047246e. __cdecl, void, two arguments read at 0x004722c0 and 0x00472354.
