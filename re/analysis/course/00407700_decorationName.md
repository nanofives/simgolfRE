## Purpose
decorationName (0x00407700) appends the scenery name of a tile to the shared text buffer 0x0051a068 and returns 1 on every path (ebx = 1 at 0x00407773, eax = 1 at 0x00407a90 / 0x00407ad7). The tile grids are 50 x 50 with cell = x*50 + y: type bytes 0x005722e8, object/variant bytes 0x0056988c and flag words 0x0053caf0. The type comes from the third argument id. id == -1 (0x00407705) takes the signed type byte of cell (x, y). An id with bit 0x100 set (`test ch,1` at 0x00407723) names placed object id & 0xff (0x0058bcb8 + o*16: kind word +0, x word +2, y word +4, landmark id dword +8) and takes the type byte at that object's cell. Any other id is the type itself. Types 0x16 and 0x15 (0x0040775d / 0x00407766) look up the object o = byte[0x0056988c + cell]. Object kind 4 calls landmarkName(id of o, 0) (0x00407a88), kind 2 appends 0x004c4c60, and other kinds append 0x004c4980 for type 0x16 or 0x004c4c54 for type 0x15. Every other type switches on its signed category byte [0x00578376 + type*0x30] through the byte table 0x00407b08 and the dword table 0x00407ae4 (index category - 4; unsigned `ja` at 0x00407785 to the default string 0x004c4c6c). Category 7 appends 0x004c4c78, 0xc 0x004c4df4, 0x12 0x004c4de8, 0x13 0x004c4e28, and 0x15 / 0x16 0x004c4980. Categories 0xd, 0x11 and 4 test further, using the course type byte 0x005a34e0 and the course record byte 0x00571ff4 + dword[0x0059bf90]*0x2e. Category 0xd (0x00407813): type 0x10, 0xd and 0xe give 0x004c4ddc and 0xf gives 0x004c4dc4, but course type 1 gives 0x004c4dcc for every type except 0x10. Other types append nothing (0x00407855). Category 0x11 (0x004077ae): type 0x13 gives 0x004c4e1c. Otherwise flag-word bit 0x20 gives 0x004c4e0c, a non-zero object byte on a cell of type 0x11 gives 0x004c4e04, and the rest gives 0x004c4df4 for course type 1 or 0x004c4de8. Category 4 (0x00407865): type 0xa gives 0x004c4df4 (course type 1) or 0x004c4ddc. Type 0xc gives 0x004c4db4 (course type 1) or 0x004c4df4. Types other than 4 give 0x004c4da8 when the course record byte is 0xd, else 0x004c4d9c. Type 4 with flag-word bit 0x1000 clear (0x004078f0) gives 0x004c4cac when the record byte is 0xa, else 0x004c4c98 (course type 1) or 0x004c4c84. Type 4 with the bit set picks one of five strings by object byte % 5, from the table 0x00407b1c for course type 1, 0x00407b30 for course type 2, or 0x00407b44 for course types 0 and 3. Any other course type appends nothing (0x004079b4).
