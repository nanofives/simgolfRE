With the third argument set it closes and returns (0x0040bab9 / 0x0040bac4). Otherwise serializeCourse 0x0040afa0 is called with 1 (0x0040bad6) and the descriptor closed (0x0040bae2); the flag word is then rewritten as (the word the load left, with the low byte's bits 2 and 3 cleared by `and al, 0xf3`) or (bit 2 of the word read AT ENTRY) or bit 30 (0x0040bae7..0x0040bb08), 0x00567afc is cleared (0x0040bafe), 0x004c2854 and 0x004c2848 are set to -1 (0x0040bb0d / 0x0040bb13) and the three terrain tables are rebuilt (0x0040bb19 / 0x0040bb1e / 0x0040bb23). With the second argument 0 it returns that 0 (0x0040bb28 / 0x0040bb31). Otherwise, unless the name equals the one at 0x004c5314 (the inline comparison 0x0040bb37..0x0040bb6e), it puts the label at 0x004c5304 in the text buffer, sets 0x004c2e08 to -1 and draws the progress window over the window object at 0x00519a60 (0x0040bb70..0x0040bbba); it applies the course type 0x005a34e0 (0x0040bbbf / 0x0040bbc7), reloads the world assets when that byte no longer equals the one read at entry (0x0040bbcc..0x0040bbde) and returns the terrain refresh's result (0x0040bbe3).
