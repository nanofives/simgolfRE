## Purpose
Converts the value in st(0) to a 64-bit integer by truncation toward zero, returns it in edx:eax and pops st(0); the VC6 CRT helper every `(int)double` cast in the game compiles to. It saves the control word (`fnstcw [ebp-2]` 0x004a6037), forces the rounding control to toward-zero whatever the caller's word says (`or ah, 0xc` 0x004a603f, `fldcw [ebp-4]` 0x004a6046), converts with `fistp qword [ebp-0xc]` (0x004a6049), restores the caller's word (`fldcw [ebp-2]` 0x004a604c) and returns the quadword (`mov eax, [ebp-0xc]` 0x004a604f, `mov edx, [ebp-8]` 0x004a6052). Callers that store an int keep the low dword. Measured side effects (log/c3/alt/c3fo_ftol_view.txt, word 0x027f, every exception masked): an exact conversion leaves the status word unchanged; an inexact one sets PE (0x20), denormal and pseudo-denormal inputs included (no DE); infinities, NaNs, pseudo-infinity, unnormals and every value outside [-2^63, 2^63) return the integer indefinite 0x8000000000000000 and set IE (0x01) only, while exactly -2^63 returns the same bits with no flag; an empty st(0) returns the indefinite with IE + SF (0x41) and TOP moved by the pop; C1 is 0 on every row (truncation never rounds up). The control word is the caller's on exit, and the result does not depend on its rounding control: the keys at 0x027f (nearest), 0x0f7f (toward zero), 0x037f (fninit's), 0x0a7f (up) and 0x067f (down) give identical rows.
