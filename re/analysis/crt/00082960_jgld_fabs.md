## Purpose
The VC6 CRT `double fabs(double)` linked into jgld.dll (the libpng call `fabs(gs - 1.0)` in png_init_read_transformations 0x10070771 and png_build_gamma_table): returns the absolute value of its argument in st(0). It sets a known control word with _ctrlfp 0x1008c320 (0x133f, mask 0xffff: all exceptions masked) and keeps the old word (the call at 0x10082970, result at [ebp-0xc]). When the high dword's exponent is all ones (`and eax, 0x7ff0; cmp eax, 0x7ff0` 0x10082983 / 0x10082988 on the top word, i.e. `(hi & 0x7ff00000) == 0x7ff00000`) it classifies the value with _sptype 0x1008c120 (0x1008299b) and branches on the result (0x100829a6..0x100829b6): class 1 (+infinity) restores the word and loads the value (0x100829ba), class 2 (-infinity) restores, loads and negates (`fchs` 0x100829e4), class 3 (a quiet NaN) returns _handle_qnan1(0x15, lo, hi, oldcw) 0x1008b3e0 (0x100829e8), otherwise (a signaling NaN) returns _except1(8, 0x15, lo, hi, value + 1.0, oldcw) 0x1008b4b0 (the `fadd qword [0x1011d030]` 0x10082a07 raising the invalid operand and making a quiet NaN). The finite path clears the sign bit of the high dword (`and edx, 0x7fffffff` 0x10082a2c), restores the word and loads the result (0x10082a4c). _handle_qnan1 and _except1 set errno and run the installed _matherr; the reimplementation (shim/src/re/c3fo.cpp section E) reproduces the classification and calls _ctrlfp, _sptype, _handle_qnan1 and _except1 through their own addresses, so those effects and the x87 result are the original's. Reimplemented in `shim/src/re/c3fo.cpp`; path-1 A/B GREEN: fabs (28 vectors, 17 distinct results, 28 changing state, `log/diff/00082960_jgld_fabs.path1.csv`).
