## Purpose
Fills a polygon given as a table of {x, y} dword pairs on the 8-bit Surface at holder+4, one scanline span at a time. NULL verts (0x0049310b) or holder (0x00493117) returns 0x10. The 8-bit base from Surface slot +0x18 (0x0049312a; 0 for a null Surface) goes to 0x0083d380 (0x00493131); a NULL base skips to the release. Otherwise 0x0083d358 = verts, 0x0083d378 = count, 0x0083d34c = colour (whole dword) (0x00493144..0x00493150), 0x0083d388 = row pitch (slot +0xe0, 0x00493169), and from the clip RECT (slot +0xcc, 0x0049317b) 0x0083d38c = right - 1, 0x0083d35c = left, 0x0083d390 = bottom - 1, 0x0083d360 = top (0x00493197..0x004931b4). count <= 0 stops (0x004931bc). The scan (0x004931d1..0x004931f4) keeps the smallest y below 0x7fff with its index (stored into the verts argument slot, 0x004931de) and stores the index of each new largest y above -0x7ffd to 0x0083d350 (0x004931e8); min >= max stops (0x004931f8). Row 0x0083d384 starts at the smallest y; two edge records walk from the top vertex in opposite directions (+0 = -1 / +1, 0x0049320e / 0x0049322c) through polyEdgeStep 0x00492ed0, either failing stops (0x00493220, 0x0049323e). While the row is below bottom - 1 (0x0049324d, 0x004932a6) a row at or below top (0x00493255) is filled by fillSpanUp 0x00493080 between the two edge x values, smaller first (0x0049325f); both edges advance by polyEdgeAdvance 0x00492fa0 (0x00493276, 0x00493287), either ending stops. Finally slot +0x24 (1) of holder+4 when non-null (0x004932b9) and returns 0. The last clip row (bottom - 1) is never filled, since the loop runs while row < bottom - 1.
