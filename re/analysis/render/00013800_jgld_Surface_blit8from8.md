## Purpose
Copies 8-bit pixels between two surfaces wherever a key byte is found, returning 0 on success, 3 when a surface or one of the two pixel addresses is missing. A null first argument returns 3 at once (0x10013821). The destination point is pulled into the first quadrant: a negative x adds itself to w, is subtracted from sx and becomes 0 (0x10013831 guards 0x10013833..0x10013845), a negative y does the same to h and sy (0x10013850 guards 0x10013852..0x10013864). An x past `this`'s width (slot +0xd8) or a y past its height (slot +0xdc) returns 0, the tests being `jle`-to-continue at 0x10013885 and 0x100138a8 so x == width is still accepted; w is then cut to width - x when x + w overflows the width (0x100138d0 skips the cut at 0x100138e9) and h to height - y likewise (0x1001390e, 0x10013927). The source rectangle (sx, sy, w, h) is built by rectFromXYWH 0x10008360 (0x10013941) and intersected by IntersectRect 0x10008590 (0x10013969) with the clip rectangle of the ARGUMENT surface, slot +0xcc called on it at 0x10013953; an empty intersection returns 0 (0x10013973). What the intersection trimmed off the left and the top is added to x and y (0x1001397c..0x10013995) and w and h become its width and height (0x10013998..0x100139a7). Both pixel addresses come from slot +0x14, the argument's at the intersection's top-left corner (0x100139bc) and `this`'s at (x, y) (0x100139eb), and either one NULL returns 3 (0x100139cd, 0x100139fc); the pitches come from slot +0xe0 (0x10013a12 for the argument, 0x10013a2c for `this`). rows and cols are the intersection's height and width (0x10013a3c, 0x10013a45) and three module globals take the loop state: 0x101284b8 the group count cols >> 2 (0x10013a54), 0x101284bc the row skip thisPitch - cols (0x10013a60) and 0x101284b0 the row skip otherPitch - cols (0x10013a6b). The copy is an inline four-way unrolled loop entered through a label stored once in edx (`jmp edx` at 0x10013acb), the label and one extra group being chosen from cols & 3 (0x10013a88..0x10013ac9) so that each row's first group is cols & 3 pixels long when that is not zero. **Each step compares the byte at EDI, which is the ARGUMENT surface's pixel (loaded at 0x10013a76), with the key, and on a match stores the byte at ESI, which is `this`'s pixel (0x10013a73), into it** (0x10013acd / 0x10013ad1 and the three repeats, plus the inverted-sense copies at 0x10013afa..0x10013b0e); so the surface that is read is `this` and the surface that is written is the one passed as the argument, at exactly the positions where that argument surface already held the key. Each row then adds the two globals to the two cursors (0x10013b1b, 0x10013b21) and the row counter is the `dec ebx` at 0x10013b27. Both surfaces are released with slot +0x24 and the argument 1, `this` first (0x10013b38) and the argument second (0x10013b4e), and the function returns 0 (0x10013b58).
