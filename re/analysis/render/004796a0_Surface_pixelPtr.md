## Purpose
Surface_pixelPtr (0x004796a0) returns the address of pixel (x, y) in the jgld.dll drawing surface held at this+4, or NULL when the point or the surface is unusable. Width and height come from the surface's virtuals at vtable +0xd8 and +0xdc (0x004796af, 0x004796ce; taken as 0 when this+4 is null, 0x004796ab / 0x004796ca) and the point is rejected when x >= width or y >= height (signed `jge` at 0x004796bf / 0x004796de; negative coordinates pass). The base pointer is the result of the virtual at +0x10 (0x004796e9) and a zero base returns NULL (0x004796f0). The bit depth is the dword the virtual at +0xe4 points at (0x004796ff..0x00479709): depth - 8 above 0x18 returns NULL (`ja` at 0x00479711), otherwise the index table at 0x00479804 selects one of five targets in the jump table at 0x004797f0: depth 8 returns base + r, 16 base + 2r, 24 base + 3r, 32 base + 4r with r = y * stride + x and stride from the virtual at +0xe0 (0x00479726..0x004797da); every other depth in 8..32 returns NULL (0x004797e4). In jgld's Surface class (vtable RVA 0x11d0b0, re/analysis/systems/jgld_2.md) those slots are width (+0x5c - +0x54), height (+0x60 - +0x58), getField40 (+0x40), getDepthPtr (this+0x24) and jgld.dll 0x10008730, which returns +0x4c0 after copying it to +0x4cc and, when non-zero, increments +0x4c8.
