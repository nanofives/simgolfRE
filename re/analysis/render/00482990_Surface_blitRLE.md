## Role (from the naming pass, not a C3 purpose)
decodes a per-scanline byte-run (brun) RLE image into the locked surface, copying literal runs (negative count) or filling repeat runs (`re/names/exe_3.tsv`)

## Purpose
Decode one byte run-length encoded image into a display's locked surface. `__thiscall` with three stack arguments (`ret 0xc` at 0x00482a70); the middle argument is never read. The destination surface is display+4 (0x004829a6): its vtable slot +0x20 is called with no argument to lock it and returns the pixel pointer (0x004829ab), and slot +0x24 is called with 1 to unlock it once the image is finished (0x00482a5f / 0x00482a66). The geometry comes from this+0x58, re-read once per row: the 16-bit width at +8 (0x004829cf / 0x004829d5) and the 16-bit height at +0xa (0x004829ae / 0x004829b9). A height of zero skips the whole decode and still unlocks (0x004829c0 / 0x004829c2), and a width of zero skips a row's runs (0x004829d9 / 0x004829df). The payload starts at chunk+6 (0x004829a3) and one byte is skipped at the start of every row (`inc ebx` at 0x004829d4). Each run is one signed count byte (0x004829e1): a negative count copies that many literal bytes (`neg cl` then `movsx ebp, cl` at 0x004829e8 / 0x004829ea, `rep movsd` + `rep movsb` at 0x004829f8 / 0x00482a05, the source advanced by the run at 0x00482a07), and a count of zero or more repeats the single following byte that many times (`movsx eax, byte ptr [ebx]` at 0x00482a0b, the byte spread over a dword at 0x00482a10..0x00482a20, `rep stosd` + `rep stosb` at 0x00482a2a / 0x00482a34, the source advanced by one at 0x00482a2e). The destination cursor is kept in the caller's third-argument slot (0x00482a01 / 0x00482a23 / 0x00482a36) and the remaining width is decremented by the run length and tested against zero, not against a lower bound (0x00482a3a / 0x00482a3e / 0x00482a44), so a row whose runs do not add up to its width exactly would keep decoding. The return value is always 0 (`xor eax, eax` at 0x00482a6a).
