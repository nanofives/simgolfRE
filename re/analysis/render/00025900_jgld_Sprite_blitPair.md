## Purpose
Draws this Sprite's 8-bit payload onto a pair of 16-bit surfaces, weighting the pixel already in the first surface by a second Sprite's payload and writing the blended result into the second surface. The colour table comes from this Sprite's own Palette at +0x10 or, when it has none, from the Palette at offset 4 of the client object the module global 0x1012873c points at (0x10025920 and 0x10025931); with neither the function releases the destination through vtable slot +0x24 with 1 and returns 16 (0x1002594e, 0x10025958). The destination's format code, element [1] of the pointer slot +0xe4 returns, selects the Palette's RGB565 table through slot +0x18 or its RGB555 table through slot +0x1c (0x100259c8, 0x100259e3); any other code releases the destination the same way and returns 1 (0x10025a0a). The rectangle is the sprite's width at +0x30 and height at +0x34 placed at the given position (0x10025a2e), intersected with the destination's clip rectangle (slot +0xcc) by IntersectRect through jgld's own import slot 0x1012c5e4 (0x10025a70); an empty intersection releases the destination and returns 0 (0x10025a97). For each pixel the payload byte of `this` is the colour index and the payload byte of `other`, read at the same offset and with THIS Sprite's pitch at +0x2c (0x10025abe), is the weight. A value of 0xff in either payload writes nothing (0x10025b91 and 0x10025b9a); a weight of 0 writes the colour table entry unchanged (0x10025c57); any other weight writes, per five-bit channel, the sum of the source field and of the destination field scaled by the weight with an 8-bit `mul cl` and shifted down by 8, the sum then divided by 8 (0x10025bd6, 0x10025c05, 0x10025c34). That sum reaches 0x1ee, so a channel result reaches 0x3d and overflows its five bits into the next field: the original does not clamp. BOTH stores go to the SECOND destination surface, through the cursor reloaded from the frame at 0x10025c4b and 0x10025c5d; the first destination is only read (0x10025bb4). Rows, columns, the source row skip and the destination row skip are parked in the module globals 0x10128578, 0x10128564, 0x1012853c and 0x10128560 (0x10025b38..0x10025b69) and the row counter is decremented in memory (0x10025c9c). On the way out the destination is released with 2 and the function returns 0 (0x10025cb8, 0x10025cc2). Reimplemented in `shim/src/re/c3bm.cpp`; path-1 A/B GREEN: Sprite::blitPair (17 vectors, 16 distinct results, 14 changing state, `log/diff/00025900_jgld_Sprite_blitPair.path1.csv`); Sprite::blitPair_nopal (5 vectors, 3 distinct results, 2 changing state, `log/diff/00025900_jgld_Sprite_blitPair_nopal.path1.csv`).
