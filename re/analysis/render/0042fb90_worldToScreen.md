## Purpose
worldToScreen (0x0042fb90) projects the world point (wx, wy) (1024 units per tile) to screen coordinates *sx / *sy and returns 1 when the point lies inside the view widened by a margin m, else 0. It reads the camera tile 0x004c2ba0 / 0x004c2ba4, the zoom 0x004c2844 (Z), the view size 0x00822c8c (W) and 0x00822c90 (H), the rotation 0x005685f4, the height scale 0x004c2e00 (S) and the flag 0x005a9cc0. It forms ix = ((wx - camX*1024 - 0x200) * Z) >> 7 and iy likewise (0x0042fb90..0x0042fbd5), rescales them by 80/64 and 52/40 when W == 0x400 (0x0042fc0f..0x0042fc3a) or by 104/64 and 68/40 when W == 0x500 (0x0042fbe8..0x0042fc3a), and applies one of four rotations (separate equality tests at 0x0042fc47, 0x0042fca3, 0x0042fd04, 0x0042fd66): rotation 0 gives X = iy + W/2 + 8Z + ix and Y = 20iy/32 - 20ix/32 + H/2; 2 gives X = W/2 - ix + iy and Y = -20ix/32 - 20iy/32 + H/2 - 5Z; 4 gives X = W/2 - 8Z - iy - ix and Y = 20ix/32 - 20iy/32 + H/2; 6 gives X = W/2 - iy + ix and Y = 20iy/32 + 20ix/32 + H/2 + 5Z (all quotients truncate toward zero). Any other rotation writes nothing and the tests read the caller's values. It returns 0 unless -m <= X < W + m and -(m/2) <= Y < m/2 + H (0x0042fdc1..0x0042fe03). Otherwise it adjusts Y for tile (wx >> 10, wy >> 10) by a term chosen by the flags dword at 0x0057837c + 0x30 * type (type = the signed byte at 0x005722e8 + tx*50 + ty): flag 8 adds nothing; flag 2 subtracts (minimum - 3) * S * Z / 4 with the minimum from cornerRange (0x0042f4b0); flag 4 subtracts (byte at 0x00543018 + cell - 3) * S * Z / 4; otherwise the four corners c_k = cornerHeights(tx, ty, k, 1) - 3 (k = 5, 7, 1, 3, 0x0040bfe0) give -c5 * S * Z / 4 when all four are equal, or the bilinear blend ((0x400-dx)*c7 + dx*c1)*(0x400-dy) + ((0x400-dx)*c5 + dx*c3)*dy, scaled by S * Z and divided by 1024, negated, divided by 1024 and by 4 (0x0042fe11..0x0042ffa6). When 0x005a9cc0 is non-zero the result is doubled about (400, 300) (X = 2X - 400, Y = 2Y - 300, 0x0042ffa8..0x0042ffc7), and the bounds test is repeated (0x0042ffc9..0x0042fffc).
