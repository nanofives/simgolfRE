## Purpose
fill16 (0x00493630) fills count 16-bit cells starting at dst with the low word of color. When count is odd (`test al, 1` / je at 0x00493648..0x0049364a) one word is stored first (0x00493650) and dst advances by 2 bytes (0x00493653); then count / 2, rounded toward zero (cdq / sub / sar at 0x0049365c..0x0049365f), dwords of (color << 16 | color) (0x00493638..0x00493642) are stored with rep stosd when that quotient is > 0 (jle at 0x00493663). A negative odd count stores the single word and nothing else; a count <= 0 that is even stores nothing. It returns nothing. Its caller is decodeImage16 (0x00495420).
