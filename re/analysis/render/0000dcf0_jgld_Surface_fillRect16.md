## Purpose
Fills one rectangle of a 16-bit surface with one colour and returns 0, or 24 when the surface's format code is neither 0 nor 1. A null rectangle means the whole surface and is forwarded to clear16 0x1000da70 (tested at 0x1000dd18, called through the thunk 0x10001a23 at 0x1000dd21). The colour block then runs exactly as in clear16 (bit-31 test 0x1000dd38, surface palette 0x1000dd4c, global fallback 0x1000dd60, format switch 0x1000dd99 / 0x1000dd9f) with the unsupported arm leaving at 0x1000dda1 for the `mov eax, 0x18` at 0x1000ddf3. The colour is masked to 16 bits (0x1000de00), the caller's rectangle is copied to a local (0x1000de0b..0x1000de1f) and intersected with the clip rectangle of slot +0xcc by IntersectRect 0x10008590 (0x1000de42); an empty intersection returns 0 (0x1000de4c). The top-left pixel address comes from slot +0x1c (0x1000de67) and a NULL one returns 0 (0x1000de78). The row skip (pitch - w) * 2 is parked in the module global 0x10128458 (0x1000dead, 0x1000deaf) and never read back; each of the h rows is written by fillWords 0x1000af30 with w words (0x1000ded1) and the cursor advances by the slot-+0xe0 pitch doubled (0x1000dee3..0x1000def6), the row counter being the post-decrement test at 0x1000deb7..0x1000dec2. Slot +0x24 with 1 closes (0x1000df07).
