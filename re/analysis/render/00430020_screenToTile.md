## Purpose
screenToTile (0x00430020) finds the tile under screen point (px, py) and writes it to *tx / *ty. When the flag at 0x005a9cc0 is non-zero it first maps the point back through the doubling, px = (px - 400)/2 + 400 and py = (py - 300)/2 + 300 (0x0043002e..0x00430061). It centres the point, cx = px - W/2 - 0x40 and cy = py - H/2 (W, H = 0x00822c8c, 0x00822c90), shifts it per rotation 0x005685f4 (2: cx + 0x20, cy + 0x14; 4: cx + 0x40; 6: cx + 0x20, cy - 0x14; 0x00430094..0x004300b5) and scales s = (cy << 5) / 40 (0x004300b8..0x004300cc). A first guess comes from the camera tile (0x004c2ba0 / 0x004c2ba4) and the divisor at 0x004c2840 (q), one formula pair per rotation, e.g. rotation 0: *tx = ((2camX + 1)q - 2s + cx) / q / 2 and *ty = (q + 2(camY*q + s) + cx) / q / 2 (0x004300d4..0x00430214, quotients truncate). It then hill-climbs (0x00430220..0x00430343): it projects the current tile to the screen with tileToScreen (0x0042f940) when useWorld is 0, or with worldToScreen (0x0042fb90) of (t << 10, (u + 1) << 10) and margin 0 otherwise, measures distance(px - a, 2(py - b)) (0x0040acd0), does the same for the eight neighbours whose offsets are the tables at 0x004c2878 (dx) and 0x004c2898 (dy), moves *tx / *ty to a neighbour whose distance is strictly smaller than the best so far, and repeats until a pass leaves the tile unchanged. The projected point (a, b) is carried from one projection to the next, so a projection that writes nothing (tileToScreen off the 50 x 50 map, or a tile it cached as off-screen, -99) is measured at the previous point. Callers: drawFlyingBall (0x004038f0) and mainLoop (0x0040f5c0).
