## Purpose
Changes a tile's terrain type, and is the only entry point that does: everything a type change implies for the mesh and the textures happens inside it. It runs three steps. First, a tile that carries a path (byte [this+0x208] read at 0x10014042, test and je 0x1001404a) gets its path-type flag [this+0x20a] set to 1 (0x1001404f), before anything else and whatever the new type is. Second, the OLD type at [this+0x24] is left: 7 calls Tile::leaveType7 (cmp 0x10014059, jne 0x1001405d, call 0x10014062 of the thunk 0x10001168) and then, as a SEPARATE if, 6 calls Tile::leaveType6 (cmp 0x1001406a, jne 0x1001406e, call 0x10014073 of the thunk 0x1000114f) while that if's else branch tests 0x11 (cmp 0x1001407d, jne 0x10014081) and sets the normals-dirty flag [this+0x244] (0x10014086) - so an old type of 7 reaches both the leave call and the 0x11 test, and 6 and 0x11 exclude each other. Third, the new type is stored (0x10014093) and dispatched through a jump table (ja 0x100140a0 for anything above 0x14, index bytes at 0x10014131, table at 0x10014115): 7 -> Tile::enterType7 (call 0x100140b7), 0x11 -> Tile::setPathFlagForType(type) (push 0x100140c1, call 0x100140c5), 6 -> Tile::enterType6 (call 0x100140cf), 0xd..0x10 -> Tile::setPathFlagForType(0xd) (push 0xd at 0x100140d6, call 0x100140db), 0 and 9 -> Tile::resetFaceTextures (call 0x100140e5), 4 and 0x14 -> Tile::reblendNeighbourhood (call 0x100140ef) and every other type -> Tile::setPathFlagForType(type) (push 0x100140f9, call 0x100140fd). Every arm therefore ends in a re-blend of the tile and the eight tiles around it, five of them through a callee. Reimplemented in `shim/src/re/c3bk.cpp`; path-1 A/B GREEN: Tile::setTypeId (144 vectors, 144 distinct results, 144 changing state, `log/diff/00014020_Terrain_Tile_setTypeId.path1.csv`).
