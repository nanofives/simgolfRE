## Purpose
Re-blends a tile and the eight tiles around it, which is what a type change on one tile needs so that the seams on all sides are redrawn. It calls Tile::blendFaceTextures 0x10013670 nine times: once for this tile with the tile's OWN type (load 0x10013520, call 0x10013527) and then for n[0], n[0]->n[2], n[2], n[1]->n[2], n[1], n[1]->n[3], n[3] and n[0]->n[3] in that order, each with the argument -1 so that each of them blends as its own type (calls 0x1001353d, 0x1001355f, 0x10013575, 0x10013597, 0x100135ad, 0x100135cf, 0x100135e5, 0x10013607). Each call is guarded by the pointers it needs, and the four diagonal ones test THIS tile's n[2] / n[3] and then dereference the other tile's (je 0x10013549 then je 0x10013552, and the same shape at 0x10013581/0x1001358a, 0x100135b9/0x100135c2, 0x100135f1/0x100135fa), so a neighbour with a NULL n[2] or n[3] hands NULL to Tile::blendFaceTextures, whose first dereference at 0x100136ca faults. `this` is re-read from [ebp-4] before every test and nothing is cached. It takes no argument, returns nothing (`ret` at 0x1001361c) and writes only what Tile::blendFaceTextures writes: the eight faces of each of those tiles.
