## Purpose
The zlib stream-level state machine on top of `inflate_blocks` 0x1009ce80: the two-byte zlib header, an optional four-byte preset-dictionary id, the deflate blocks and the four-byte adler32 trailer, as a `while (1) switch (z->state->mode)` over fourteen modes (jump table 0x1009c79d). Unlike `inflate_blocks` it keeps nothing in locals: every byte is taken straight out of the z_stream by `z->avail_in--, z->total_in++, *z->next_in++` (0x1009c17a-0x1009c1c1) and a mode that runs out of input returns the running code unchanged (0x1009c169 and nine more). A null stream, a null state, a null `next_in` or a negative flush argument all return Z_STREAM_ERROR (0x1009c10c-0x1009c123). METHOD rejects anything but deflate (0x1009c1c6) and a window larger than the one the state was created with (0x1009c208); FLAG rejects a header whose two bytes are not a multiple of 31 (0x1009c2a3) and, when bit 0x20 is set, goes through DICT4..DICT1 to collect the dictionary id into `z->adler` and returns Z_NEED_DICT (0x1009c4b5), after which DICT0 refuses every further call until `inflateSetDictionary` replaces the mode (0x1009c4e2). BLOCKS runs the deflate blocks, turns a Z_DATA_ERROR into the BAD mode with `sub.marker` 0 so `inflateSync` can be tried (0x1009c521) and passes anything that is not Z_STREAM_END back to the caller (0x1009c531); on a finished stream it resets the block state, keeping the check value it computed in `sub.check.was` (0x1009c55a), and goes straight to DONE when the undocumented nowrap option is set (0x1009c574). CHECK4..CHECK1 then rebuild the stored adler32 and compare (0x1009c73f); a mismatch is "incorrect data check" 0x101207fc with `sub.marker` 5, which says `inflateSync` cannot help. Every error mode sets that marker to 5 except DICT0's and the block-level one, which set 0.
