## Purpose
Empties the list, handing every node it does reach to that node's own scalar deleting destructor, and then resets the four fields that describe the chain. An empty list returns at once (`cmp [m_head],0` at 0x10006e10, the `jne` at 0x10006e14 skipping the `jmp` to the epilogue at 0x10006e16). Otherwise it pins `first` = m_head->next in [ebp-0xc] (0x10006e21) and walks `n` from first->next (0x10006e2a): while n is not m_head (0x10006e41 / `je` 0x10006e44) it unlinks n by writing n->next into first->next (0x10006e4f), calls slot 0 of n's own vtable with the argument 1 (`push 1` at 0x10006e66, `call [edx]` at 0x10006e70 - the compiler-generated scalar deleting destructor, which is what reaches operator delete), and re-reads n from first->next (0x10006e35). After the loop it deletes m_head the same way (0x10006ea8) and writes m_ordered = 0 (0x10006ec0), m_count = 0 (0x10006eca), m_head = 0 (0x10006ed4) and m_cur = 0 (0x10006ede), in that order; m_data at +4 and m_flag at +8 keep their stale values. **The loop shape leaves one node alive for every list of two nodes or more:** it starts at first->next and ends when it comes back to m_head, so the node at m_head->next is itself never passed to a deleting destructor unless it IS m_head, which only happens in a one-node list (where m_head->next points back at m_head). The A/B measures that directly - with the deleting destructor counting its calls into node+0x14, a list of k nodes shows k-1 marks for k >= 2 and 1 mark for k = 1.
