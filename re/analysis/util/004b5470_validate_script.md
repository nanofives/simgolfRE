## Purpose
Checks the caller-supplied scan script in `cinfo->scan_info` and, as a side effect, decides whether the file will be a progressive JPEG. Its 0xa48-byte frame (0x004b5470) holds the two working arrays the checks need: a one-int-per-component `component_sent` at esp+0x30 and a `last_bitpos[10][64]` at esp+0x58 that remembers, per component and per DCT coefficient, the successive-approximation bit position last transmitted; only the leading `num_components` entries are initialised, by the `rep stosd` at 0x004b54ec (num_components dwords of 0 for the sequential case, (num_components & 0xffffff) << 6 dwords of -1 for the progressive one, 0x004b54dc / 0x004b54e6). A `num_scans` (cinfo+0xa0) that is not positive raises ERREXIT 0x11 with 0 in msg_parm[0] (0x004b5489 / 0x004b548e / 0x004b5497). The FIRST scan alone picks the mode: Ss zero together with Se equal to 0x3f, i.e. a scan carrying the whole coefficient block, clears progressive_mode (cinfo+0xdc, 0x004b54ae / 0x004b54b4 / 0x004b54b9) and anything else sets it (0x004b54ce). Each scan is then walked (0x004b54ee / 0x004b5788, with scanno starting at 1 and num_scans re-read at 0x004b5774): comps_in_scan outside 1..4 raises ERREXIT 0x18 carrying the count and 4 (0x004b550d / 0x004b5512 / 0x004b5517 / 0x004b5525), a component_index outside 0..num_components-1 (0x004b553e / 0x004b5543) or not strictly greater than its predecessor, which forces SOF order inside a scan (0x004b5561 / 0x004b5565), raise ERREXIT 0x11 with the scan number. A progressive scan (0x004b559f / 0x004b55b6) must have 0 <= Ss < 0x40, Ss <= Se < 0x40 and both Ah and Al in 0..0xd (0x004b55be..0x004b55de, ERREXIT 0xf), a DC scan (Ss == 0) must not also carry AC coefficients (0x004b5600 / 0x004b5604) and an AC scan must name exactly one component (0x004b561f / 0x004b5622); each of its components then walks its own 64-entry row of last_bitpos, addressed by component_index << 8 bytes (0x004b565b / 0x004b565d / 0x004b5662), where an AC scan whose DC entry is still -1 is rejected as sent before its DC scan (0x004b5666 / 0x004b566b) and, for every coefficient from Ss to Se (0x004b5695 / 0x004b569b / 0x004b56e2), a first visit must have Ah == 0 (0x004b56a5 / 0x004b56ad) and a later visit must continue exactly where the previous scan stopped, Ah equal to the stored value and Al equal to Ah-1 (0x004b56b5 / 0x004b56b7 / 0x004b56be / 0x004b56c0), the entry then taking Al (0x004b56dc). A sequential scan instead demands Ss, Se, Ah, Al equal to 0, 0x3f, 0, 0 (0x004b5704..0x004b5713) and that no component is sent twice, the flag being tested and then set (0x004b573e / 0x004b5744 / 0x004b5764). The closing pass raises ERREXIT 0x2c once per component whose data never arrived — a still-negative DC entry in progressive mode (0x004b57aa / 0x004b57ad, row stride 0x100 at 0x004b57c0) or a clear component_sent flag in sequential mode (0x004b57e7 / 0x004b57ea) — re-reading num_components at the bottom of both loops (0x004b57bc, 0x004b57f9).
