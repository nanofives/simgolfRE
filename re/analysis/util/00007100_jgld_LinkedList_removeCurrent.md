## Purpose
Unlinks the node m_cur points at, deletes it through its own vtable and moves the cursor back one node. An empty list returns at once (0x10007120 / `jne` 0x10007124, `jmp` 0x10007126). A one-node list is recognised by m_head == m_head->prev (0x10007137 / `jne` 0x1000713a) and is emptied whole: m_head is deleted (`push 1` / `call [eax]` at 0x10007153-0x1000715d) and m_head, m_cur and m_count are zeroed (0x10007175, 0x1000717f, 0x10007189) - note that this arm ignores m_cur completely, so it removes the head even when m_cur pointed somewhere else, and that m_data and m_flag are left stale. Otherwise (from 0x10007195) it first moves the head back if the cursor is standing on it (`m_head == m_cur` at 0x1000719e / `jne` 0x100071a1, m_head = m_head->prev at 0x100071af), keeps the victim n = m_cur (0x100071b8), steps the cursor to m_cur->prev (0x100071c7) and re-mirrors the payload of the NEW current node into m_data (0x100071d6) and the one byte m_flag (0x100071e5); only then does it splice the victim out, n->next->prev = n->prev (0x100071f4) and n->prev->next = n->next (0x10007203), delete it (0x10007224) and decrement m_count (0x1000723f / 0x10007245). Its caller is Tracked::dtor 0x10006b80, which calls LinkedList::find 0x100072b0 on the module-level tracked-object list first and then this function, so "current" there means "the object that was just found".
