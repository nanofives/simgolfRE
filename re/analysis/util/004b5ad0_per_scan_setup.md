## Purpose
Computes the MCU geometry of the scan that is about to be emitted. A single-component scan (comps_in_scan, cinfo+0xec, equal to 1 at 0x004b5add / 0x004b5ae5) is non-interleaved, so an MCU is one block: MCUs_per_row (cinfo+0x100) is the component's width_in_blocks (0x004b5aed / 0x004b5af0), MCU_rows_in_scan (cinfo+0x104) its height_in_blocks (0x004b5af6 / 0x004b5af9), MCU_width, MCU_height, MCU_blocks and last_col_width are 1 and MCU_sample_width is 8 (0x004b5b09..0x004b5b19), last_row_height is height_in_blocks modulo v_samp_factor or v_samp_factor itself when that UNSIGNED division leaves no remainder (0x004b5b07 / 0x004b5b1c / 0x004b5b1e / 0x004b5b20 / 0x004b5b22), and the MCU holds one block of component 0 (0x004b5b25 / 0x004b5b2b). An interleaved scan (0x004b5b3a) first raises ERREXIT 0x18 with the count and 4 when comps_in_scan is outside 1..4 (0x004b5b3c / 0x004b5b3e / 0x004b5b43 / 0x004b5b48 / 0x004b5b57 / 0x004b5b5c), then measures the row in iMCUs: MCUs_per_row = jdiv_round_up(image_width, max_h_samp_factor * 8) (0x004b5b6a..0x004b5b8b) and MCU_rows_in_scan = jdiv_round_up(image_height, max_v_samp_factor * 8) (0x004b5b7d..0x004b5b96), clears blocks_in_MCU (0x004b5ba7) and walks cur_comp_info (0x004b5bb1 / 0x004b5c6b). Each component contributes h_samp_factor by v_samp_factor blocks to the MCU: MCU_width = h_samp_factor (0x004b5bd1), MCU_height = v_samp_factor (0x004b5be7), MCU_blocks their product (0x004b5be4 / 0x004b5bea), MCU_sample_width = h_samp_factor * 8 (0x004b5bd4 / 0x004b5bdd), last_col_width = width_in_blocks modulo h_samp_factor or h_samp_factor itself (0x004b5be2 / 0x004b5bed / 0x004b5bf1 / 0x004b5bf6) and last_row_height = height_in_blocks modulo v_samp_factor or v_samp_factor itself (0x004b5bfb / 0x004b5bfd / 0x004b5c01 / 0x004b5c03), both from UNSIGNED divisions. A running total above 10 raises ERREXIT 0xb (0x004b5c06 / 0x004b5c0c / 0x004b5c11 / 0x004b5c16); otherwise MCU_blocks entries of MCU_membership (cinfo+0x10c) are set to the component's position in the scan and blocks_in_MCU (cinfo+0x108) grows by one per entry (0x004b5c24 / 0x004b5c29 / 0x004b5c38 / 0x004b5c45 / 0x004b5c4d), so the membership array says which component each block of an MCU belongs to. comps_in_scan is re-read at the bottom of every pass (0x004b5c57). Both paths end with the restart interval: a positive restart_in_rows (cinfo+0xc4, 0x004b5c72 / 0x004b5c7a) sets restart_interval (cinfo+0xc0) to restart_in_rows * MCUs_per_row clamped to 0xffff (0x004b5c7c / 0x004b5c83 / 0x004b5c88 / 0x004b5c8f), the largest value the DRI marker can carry.
