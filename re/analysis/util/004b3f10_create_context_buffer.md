## Purpose
Gives every component a colour buffer with one row group of context above and below, for the downsamplers that need neighbouring rows. One block of `num_components * max_v_samp_factor * 5` row pointers comes from `mem->alloc_small` (0x004b3f23 imul, 0x004b3f2f lea *5, 0x004b3f32 shl 2, call at 0x004b3f39) and is kept in the caller's argument slot (0x004b3f41): five row groups' worth of pointers per component. For each component a real buffer of `3 * max_v_samp_factor` rows comes from `mem->alloc_sarray(cinfo, JPOOL_IMAGE, width_in_blocks * max_h_samp_factor * 8 / h_samp_factor, 3 * max_v_samp_factor)` (0x004b3f7b, 0x004b3f82..0x004b3f96), and its row pointers are copied into the MIDDLE of the fake array, at fake + max_v_samp_factor (0x004b3fa0, `rep movsd` of 3 * max_v dwords whose byte count is computed once at 0x004b3f59 and reloaded at 0x004b3fa9). The wraparound then makes the array behave as a cylinder (0x004b3fb7 / 0x004b3fec): `fake[i]` takes `true[2 * max_v + i]` (0x004b3fc8 / 0x004b3fd1 / 0x004b3fd6) and `fake[4 * max_v + i]` takes `true[i]` (0x004b3fc1 shl 4 / 0x004b3fd9 / 0x004b3fdb), for i below max_v_samp_factor, so the row group above the first one is the last real group and the group below the last one is the first real group. The component's slot in the colour-buffer array at prep+8 (prep read from cinfo+0x14c at 0x004b3f29, cursor set at 0x004b3f62) gets `fake + max_v` (0x004b3ff9) and the fake cursor moves on by `5 * max_v` pointers (0x004b3ff6 / 0x004b4002). `num_components` is re-read at the bottom of every pass (0x004b4015).
