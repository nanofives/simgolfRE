## Purpose
Turns a grey row into an RGB one in place, writing backwards from the end of the expanded row, and then rewrites the header. The width is read first (0x1007332b). Two guards return without any change: bit_depth below 8 (`cmp eax, 8` / `jl 0x100736b9` at 0x10073338-0x1007333b, signed on the zero-extended byte) and bit 1 of color_type already set (`and edx, 2` / `jne 0x100736b9` at 0x10073349-0x1007334e). color_type 0 (`test ecx, ecx` / `jne 0x100734b4` at 0x1007335c-0x1007335e) is grey and color_type 4 (`cmp eax, 4` / `jne 0x10073668` at 0x100734bc-0x100734bf) grey+alpha; any other value that passes the guards reaches the tail with no pixel moved. Inside each, bit_depth 8 (`jne` at 0x1007336f / 0x100734d0) selects the one-byte sample loop and any other depth the two-byte one. The four loops start at sp = row + width * s - 1 and dp = sp + width * t (s, t = 1, 2 for grey/8; 2, 4 for grey/16; 2, 2 for grey+alpha/8; 4, 4 for grey+alpha/16) and replicate the grey sample three times per pixel, keeping the alpha sample ahead of it where there is one; all four counters are compared with the width unsigned (`jae` at 0x100733a2, 0x1007341e, 0x10073507, 0x1007359f), so width 0 moves nothing. The tail at 0x10073668 adds 2 to channels as a byte (`add dl, 2` at 0x1007366e), sets bit 1 of color_type (`or dl, 2` at 0x1007367d), recomputes pixel_depth as the UPDATED channels times bit_depth truncated to a byte (`imul edx, ecx` at 0x10073696 over the value read back at 0x1007368b, stored at 0x1007369c) and rowbytes as (width * pixel_depth + 7) >> 3 with the pixel_depth just written (read back at 0x100736a4, `add eax, 7` / `shr eax, 3` at 0x100736ad-0x100736b0, stored at 0x100736b6).
