# Portable runtime: how SimGolf runs on Windows 11 with no install, no registry, in a window

Established 2026-10-02. Every step is reproducible from `SM_SIMGOLF.iso` (anchor in `re/anchors.json`).
Read this before touching anything under `original/` or `shim/`.

## 1. Media

| Item | Finding |
|------|---------|
| Installer | InstallShield 6 (`data1.hdr` + `data1.cab`/`data2.cab`, `setup.inx`, `ikernel.ex_`) |
| Copy protection | **SafeDisc 2.60.52** (`secdrv.sys`, `drvmgt.dll`, `00000409.016/.256`; signature `BoG_ *90.0&!!  Yy>` + version dwords `2, 0x3c, 0x34` at file offset `0xfd4`; sections `stxt774`, `stxt371`; `.text` entropy 7.98) |
| Patch on disc | `Patch\SimGolf_Patch_v103.exe` (WinZip SFX) -> `golf.exe` v1.03, still SafeDisc 2.60.52 |
| Engine | Firaxis **Jackal** (the Alpha Centauri engine: `jackal.txt` still carries SMAC error strings). `jgl(d).dll` = GDI/DIB 2D, `Terrain.dll` = OpenGL 3D terrain, `binkw32.dll` = RAD Bink 1.x video, `sound.dll` = DirectSound/winmm |

## 2. Extraction without running the installer

1. `7z x SM_SIMGOLF.iso -oiso`
2. `tools/src/unshield` (twogood/unshield 1.6.2, built with MSVC + zlib 1.3.1 by `build_msvc.bat`;
   needs `/std:c17 /Zc:preprocessor /DHAVE_CONFIG_H`) -> `unshield -d extracted/cab x iso/data1.hdr`
3. `original/` = `Program_Files_(ENGLISH)` + `Program_Executable_(ENGLISH)` groups, plus the CD-root
   files the game reads at boot (`jackal.txt`, `AutoSaveBase.pcx`, `AutoSaveButtons.pcx`), plus the
   v1.03 `golf.exe` (retail v1.00 kept as `golf.v100.safedisc.exe`).

## 3. SafeDisc removal -> `golf_clean.exe`

- `secdrv.sys` is blocklisted on Win11, so the protected exe cannot run natively.
- `nckstwrt/SafeDiscLoader2` (built from source, `tools/src/SafeDiscLoader2`; `VersionInjector`
  manifest changed `RequireAdministrator` -> `AsInvoker`) emulates the secdrv IOCTLs. The protected exe
  then decrypts and runs, but returns from WinMain with exit code 0 right after reading `jackal.txt`
  (U-0002). Not pursued: it is not the RE target.
- **Unwrap:** `Safedisc2Cleaner v1.2.0` (r!sc / waste_me / bOOls eYe, the nckstwrt build that loads
  `version.dll`) driven unattended by `tools/unwrap/drive_cleaner.py` (pywinauto, must run elevated).
  The first attempt failed with "Unable to get TEA key"; the run with `version.json` present
  succeeded. Output `SD2cleaned.exe` -> `original/golf_clean.exe`.
- Result (checked by `tests/test_static.py`): sections `.text .rdata .data .rsrc` only, `.text`
  entropy 6.65, EP `0x004a682f` (CRT startup; WinMain `0x0045baf0` is called from `0x004a690a`),
  149 rebuilt imports from KERNEL32, USER32, WINMM, binkw32, Terrain. **No ADVAPI32: the game never
  reads the registry.**
- `golf_clean.exe` is the RE target and the A/B reference. **Never patch it on disk.** Its SHA-256
  is anchored; patches go through the shim (section 6).

## 4. Registry and fonts

- No game module imports ADVAPI32 (only SafeDisc's `drvmgt.dll`). The installer's keys
  (`Software\Electronic Arts\EA Games\Sid Meier's SimGolf\ergc`, App Paths, Uninstall) are unused.
- The two TrueType fonts are loaded by Jackal itself (`AddFontResourceA` / `CreateScalableFontResourceA`
  imported by `jgld.dll`), session-scoped. No font install needed.
- Folders the installer creates: the game saves with `CreateFileA("saved games\<name>.sve")` relative to its
  working directory (`original\`), observed with a Frida hook on CreateFileA/W (2026-10-03). Without that
  folder "Save the Current Game" fails with no message. `re/tools/scenario.py` (`load_saved_game`) creates
  `original\saved games\`; the folder is gitignored. Autosaves land there as `&AutoSave<n>.sve`.

## 5. Windows 11 compatibility problems found, and the shim's fix for each

`shim/` builds `winmm.dll`, a proxy for the real SysWOW64 winmm (192 forwarded exports, generated by
`shim/gen_winmm_proxy.py`) that installs MinHook hooks in `DllMain`. `golf_clean.exe` imports WINMM, so the
proxy loads automatically from the game folder. Config: `original/simgolf_shim.ini`, env overrides
`SIMGOLF_*`. Log: `original/simgolf_shim.log`.

| Problem (evidence) | Fix (`[shim]` key) |
|---|---|
| `jgld.dll` calls `ChangeDisplaySettingsA(800x600x16, CDS_FULLSCREEN)` and creates a `WS_POPUP` "JackalClass" window sized to `GetSystemMetrics(SM_CX/CYSCREEN)` | `windowed=1`: suppress the mode switch, report an 800x600 screen, framed centred window, pin its position, neutralise `ClipCursor` |
| Intermittent access violation inside `binkw32!BinkBufferOpen` while opening the intro movie (`BINKBUFFERAUTO`, flags 0: Bink picks a DirectDraw primary/overlay path) | `bink_dib=1`: force `BINKBUFFERDIBSECTION` (type 2). `BinkBufferGetDescription` reports "DIB Section" |
| Intro movie costs ~15 s per boot in tests | `skip_intro=1` (off for play): `BinkOpen("...introfinal.bik")` returns NULL; the game goes straight to the menu |

Mouse input needed no fix: the game pairs `GetCursorPos` with `ScreenToClient` (~90 calls/s at the
menu) and takes clicks from window messages. For unattended tests the shim exports
`SimGolfShim_SetVirtualCursor`, so `GetCursorPos` reports a chosen client point and the user's real
mouse is never moved.

## 6. Patches and reimplementations

- **Byte patches**: `patches/*.ini` (module, rva, expect, write). The shim verifies the expected bytes
  before writing, refuses on mismatch, and defers patches for DLLs loaded later (`jgld.dll`) until
  `LoadLibraryA` returns. `tests/test_patches.py` checks every committed patch against the anchors.
- **Reimplementations**: `shim/src/re/*.cpp`, registered with `SG_HOOK(module, addr, name, detour, orig)`,
  toggleable per address (`[hooks] <addr>=0`, `SIMGOLF_HOOKS_OFF`). `SimGolfShim_FindHook` exposes the
  trampoline so `re/frida/diff_hook.py` can A/B original vs reimplementation in the live process.

## 7. Process facts the harness depends on

- **Single instance.** A second copy exits ~2 s after start. A leftover instance makes every new boot
  "die" mysteriously; `Game.start()` refuses to start while any JackalClass window exists, and never
  kills a process it did not spawn.
- The game window is DPI-unaware: on a 125% display the 800x600 client is bitmap-scaled to 1000x750
  physical pixels. `Game.shot()` resizes back to 800x600 game space.
- At spawn, only ntdll/kernel32/user32 are mapped. Hook DLL exports (binkw32, Terrain) from Frida via
  `Process.attachModuleObserver`, not `getModuleByName` at load time.
- Frida `NativeCallback` / `Interceptor.replace` on stdcall APIs must pass the `'stdcall'` ABI; the
  debug CRT in `jgld.dll` catches the ESP imbalance otherwise.
