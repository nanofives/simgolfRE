## Purpose
Stops a sound group and its member groups. this's slot +0x5c runs first (0x10039b35). With the member count at this+0x1438 above 1 (signed, 0x10039b3e / 0x10039b41) the members 1 .. count-1 stored from this+0x1440 are walked, the count being reloaded every pass (0x10039b6d, `jl` 0x10039b79): a non-NULL member is stopped by this same function through the thunk 0x100016a4 (0x10039b56), then the slot is reloaded and a member still there is destroyed through its slot 0 with 1 (the deleting destructor, 0x10039b5b-0x10039b65), and the slot is cleared (0x10039b67). The count is then set to 1 (0x10039b7c). Bit 1 of the byte at this+0xc8 (0x10039b87 / 0x10039b8e) releases the channel buffers through Channel_releaseBuffers (thunk 0x10001d11, ecx = this+0x70, 0x10039b93), clears bit 0 of this+0x44 (0x10039b98-0x10039b9e) and returns that call's result; without it 0x14 is returned (0x10039ba3). In the A/B the nested calls on members run the hooked body in both arms (Frida's Interceptor follows the thunk's `jmp`, so the thunk cannot be stubbed apart from the function); the members are groups with count 0 and both flag values.
