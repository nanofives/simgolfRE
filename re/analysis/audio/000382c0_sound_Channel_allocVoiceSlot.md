## Purpose
Finds the channel's first free voice record by counting the consecutive busy bits of its allocation mask. __thiscall, one stack argument (`ret 4` at 0x100382ef and 0x10038303): a pointer to an out counter. The mask is bits 12..27 of the channel flag dword (`shr eax, 0xc` at 0x100382c7, `and eax, 0xffff` at 0x100382ca, so bits 28..31 are dropped). The counter is zeroed first (`mov dword [edx], 0` at 0x100382cf), and while the mask's bit 0 is set (`test al, 1` with `je 0x100382e6` at 0x100382d5, the same test at 0x100382df with `jne 0x100382da` closing the loop) the counter is incremented in memory and the mask shifted right one (0x100382da to 0x100382e3), so the counter ends as the number of consecutive set bits starting at bit 12 and can reach 0x10 because the mask is 16 bits wide. The counter is then re-read from memory (0x100382e6) and compared with 0x10 (`cmp edx, 0x10` at 0x100382e8, `jb 0x100382f2`): 0x10 or more returns 0 (`xor eax, eax` at 0x100382ed), meaning no free record, otherwise the address of that record is returned, 0x238 + count*0x110 from the channel (`shl`/`add`/`shl` at 0x100382f4 to 0x100382f9 and `lea eax, [eax+ecx+0x238]` at 0x100382fc). The scan stops at the first clear bit, so a mask with a gap (0xaaaa, 0xfffe) reports slot 0 even though higher bits are set.
