## Role (from the naming pass, not a C3 purpose)
Scans an SMF track from +0x3c summing VLQ deltas until it reaches tick param_2, then stores the read position (tick +0x40, byte ptr +0x2c, delta +0x4c); returns SNDERR 0x29 if the tick is past the track end. (`re/names/sound_3.tsv`)
System writeup: `re/analysis/systems/sound_3.md`.

## Purpose
Advances a MIDI track record to the last event at or before a tick limit, recording the controller-7 values it passes in the sequencer's channel block. The track bytes come from [track+0x3c] (0x1002492d) and the running status, the consumed byte count, the accumulated ticks and a "one event was consumed" flag all start at 0 (0x1002492b-0x1002493e). Each round calls Midi_readVarLen 0x1001e710 through the thunk at 0x1000139d (0x10024948) for the delta time and stops as soon as the accumulated ticks would exceed the limit (`ja 0x10024a0e` at 0x1002495c, UNSIGNED): a walk that never completed a round returns 0x29 and writes nothing (0x10024a19), otherwise the cursor is stored at [track+0x2c], the consumed byte count at [track+0x40] and the ticks BEFORE this delta at [track+0x4c], and the function returns 0 (0x10024a4d-0x10024a5f). Inside the limit the ticks are updated (0x10024962) and the cursor advances past the delta (0x1002496c). A byte with bit 7 set becomes the running status and is stored whole at [track+0x30] (0x1002498c); when its high nibble is not 0xf0 the low nibble is stored at [track+0x48] as the current channel and the status becomes the high nibble (`je 0x10024999` at 0x1002498f). A status outside 0x80..0xff returns 0x12 (`ja 0x10024a3e` at 0x100249a1). Otherwise the byte table at 0x10024a78, read through the jump table at 0x10024a64, gives the event length: 0x80 and 0x90 skip two data bytes (0x10024a03), 0xc0 and 0xe0 skip one (0x100249de), 0xb0 is the controller case and 0xff the meta case, and every other status returns 0x12 (0x10024a3e). The controller case stores the controller's value at [this + 0x254 + channel * 0x4c] when the controller number is 7 (`jne 0x10024a03` at 0x100249e8, the index `channel * 19` built at 0x100249f2-0x100249f5, store at 0x100249fc) before skipping its two data bytes. The meta case ends the walk on meta type 0x2f, storing the cursor as it was before the delta at [track+0x2c] and the accumulated ticks at [track+0x4c] and returning 0x29 (0x10024a25-0x10024a3b); any other meta type is skipped by decoding its payload length with Midi_readVarLen and advancing past the length, the payload and the type byte (0x100249bf-0x100249d5).
