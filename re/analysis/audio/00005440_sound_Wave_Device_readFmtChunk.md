## Purpose
Reads a stream-format chunk of a sound file through mmio and, for type 3, builds its stream object; called by loadSoundFile 0x100041d0 through the thunk 0x10001870 (0x100045ec). A CtrlObject is built on the stack (CtrlObject::ctor, thunk 0x10001ffa, 0x10005461; vtable then 0x1005b178, 0x10005466). mmioRead on the HMMIO +0xa48 reads a tag, a size n and n bytes into the CtrlObject's +0x10 (0x10005488-0x100054ab). When the dword at the CtrlObject's +0x1c is 3 (0x100054ad): a 0xe4-byte Ctrl5b5c0 object (operator new 0x100054be, Ctrl5b5c0_ctor 0x100054d5) gets three (size, bytes) reads at its +0x20, +8 and +0x58 (0x100054fa-0x10005550), its embedded record +0x2c copies the CtrlObject's dwords +4..+0x24 (0x10005552-0x10005592), and a node for the record is appended to the list +0xa4c / +0xa50 with the count +0xa58 raised (0x100055b6-0x100055e0), which eax returns; other types return the third mmioRead's result. Two facts of the original: the copy at 0x1000555b reads the CtrlObject's +8, which neither the constructor nor the read writes (stale stack); and the read can reach the CtrlObject's +0x28, the SEH record link that 0x100055e6 / 0x100055ed reload into fs:[0], when n exceeds 0x18.
