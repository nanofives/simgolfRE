## Purpose
Picks a track slot round-robin and schedules an event on it. A zero track count at this+0x23c returns 0 at once (`je` 0x100247cc -> 0x10024888). Otherwise the module counter 0x100b5010 is incremented and wrapped to 0 when it reaches +0x23c (`jl` 0x100247e5), the track index table this+0x238 is read at [counter] (0x100247f9) and Seq_listGetAt (thunk 0x100015fa, on this+0x60) writes the track to a local out slot and returns 0 when found (0x10024804). If found (`jne` 0x1002480b skips the scan) and +0x23c > 0 (signed `jle` 0x1002481a), a scan ebp = 1 .. +0x23c - 1 runs: a track whose +0x38 bit 2 is clear is marked (`|= 4`, 0x1002486b) and the scan stops; an occupied track advances the counter and re-reads (a found result stops it, `jne` 0x1002485a; the index wraps, `jl` 0x10024867). Finally Seq_scheduleEvent (thunk 0x1000240a) is called with (this; the out track, this+0x71c, 0x20, 0) (0x1002487f) and its eax returned. Twelve sequencers vary the count, present/absent tracks and occupied bits to reach: first slot free, first occupied then a later free, all occupied (scan exhausted), the single-slot free and occupied cases, a first not-found (schedule the null out) and the count-0 early return.
