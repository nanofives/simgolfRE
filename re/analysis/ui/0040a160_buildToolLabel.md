## Purpose
buildToolLabel (0x0040a160, cdecl, tile x and y) writes the build/remove cursor label for a tile into the shared text buffer 0x0051a068 and returns 1 when the label names a removable placed item, else 0. A blocked tile (tileBlocked 0x0040bf60, which also rejects coordinates outside 0..49) gets the string at 0x004c515c and returns 0 (0x0040a178). Otherwise, with cell = 50x + y (0x0040a1a6..0x0040a1b5) and the 16-bit flag word at 0x0053caf0 + 2*cell: bit 0x8000 gives the string 0x004c5150, return 0 (0x0040a1c0); bit 0x400 with a placed object on the tile (objectAt 0x0040df80 != -1) gives 0x004c5144 followed by the object's type name at 0x004c26b0 + 20*type (type = the word at 0x0058bcb8 + 16*index), return 1 (0x0040a1f7..0x0040a243). Then the item byte at 0x005830b8 + cell decides: 0x80..0xfe give 0x004c5134, replaced by 0x004c5128, 0x004c5118, 0x004c5104 or 0x004c50ec for the kinds (item & 0x7f) 0, 1, 0x10 and 0x13, return 1 (0x0040a258..0x0040a30d); 0..0x7c give 0x004c50e0 followed by the name at 0x00578350 + 48*item, return 1 (0x0040a328..0x0040a38f). Items 0x7d..0x7f and 0xff fall to the flag word again (0x0040a39b): bit 0x200 gives 0x004c5118, bit 0x400 with an object 0x004c50d8 plus the object name, bit 0x20 gives 0x004c5128, bit 0x1000 gives 0x004c5134, else an empty string; all return 0.
