## Purpose
Move the focus of a window's parent to the next visible child, called on the child (this). It does nothing without a parent at this+0x130 (0x0047af63..0x0047af6b) or when the parent's child count +0x140 is not above 1 (0x0047af71 / 0x0047af78, signed). It saves the parent's current child (the cursor node +0x13c's +4, or none when the head +0x138 is null, 0x0047af7e..0x0047af93) in 0x0083ab98 (0x0047af95). Then, at most count times (0x0047afa1..0x0047b019), it steps the cursor to the node's +0xc link, increments the index +0x144 and wraps it to 0 when it reaches the count (0x0047afb7..0x0047afdd), and stops at the first child Window::visible 0x004801f0 accepts (0x0047afe7..0x0047b00a). When the child now under the cursor is the saved one (0x0047b01b..0x0047b03e) it returns; otherwise this window's own slot +0xf0 is called with 0 (0x0047b040..0x0047b046), the parent's head and cursor are read again (0x0047b04c..0x0047b062) and, when the head and the cursor node's child are both set (0x0047b05d / 0x0047b067), that child's slot +0xf0 is called with 1 (0x0047b069..0x0047b06d). A null head with a count above 1 hands Window::visible a NULL child (ecx = 0 at 0x0047b001 / 0x0047b003), which reads [0xa0] and faults in the original, so no vector passes one.
