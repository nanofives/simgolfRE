### 2. port/src/sim/menu.cpp (not S3's file): three edits

(a) Include, beside `#include "portsim/sim/gfx.h"` (or after `#include "portsim/sim/course.h"`):

```cpp
#include "portsim/sim/flic.h"
```

(b) In `load_flic`, the column read (S3.4b: the switch acts on the column path with or without a graphics backend, because the
original dies on a tropical course whether or not anything is drawn and the underscore names change the sheet's columns, which
decide later cell allocations):

```cpp
  const int32_t cols = flic_cols(ctx, read_str(ctx.mem, text));
```

becomes

```cpp
  const int32_t cols = flic_cols(ctx, flic::resolve_name(ctx.files(), read_str(ctx.mem, text)));
```

(c) In `load_flic`, the overflow test's else branch (today):

```cpp
  } else {
    gs.g_sheetFirstCell[id] = base;
    const int32_t cells = frames > 0 && cols > 0 ? (f.delay == -1 ? 1 : mul32(frames, cols)) : 0;
    gs.g_cellCursor = add32(base, cells);
  }
```

becomes

```cpp
  } else {
    gs.g_sheetFirstCell[id] = base;
    const int32_t cells = frames > 0 && cols > 0 ? (f.delay == -1 ? 1 : mul32(frames, cols)) : 0;
    gs.g_cellCursor = add32(base, cells);
    // the cells' pixels for an attached graphics backend (S3.4, portsim/sim/flic.h): loadFlic's frame-by-frame cut of the
    // flic into the sheet's cells g_cellPool[base ..], judged against the original's sheet memory (port/test/test_flic.py)
    if (g_gfx_attached.load(std::memory_order_relaxed) != 0)
      flic::sheet_to_gfx(ctx, path, f.frames, f.delay, f.flag,
                         state_va(ctx, &GameState::g_cellPool) + 0x2cu * static_cast<uint32_t>(base));
  }
```

`path` is load_flic's existing `const uint32_t path = ctx.mem.data_base() + f.path;`. `f.delay` is loadFlic's fourth argument (the
decoder calls it `size`); `f.frames` is passed as given. Cost: one decode per load while a backend is attached (about 500 at boot plus
114..120 per course). At switch 1 the sheet_to_gfx call is never reached for a missing Tree name (edit b has already faulted).
