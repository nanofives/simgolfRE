## 3. U-1673 and the controls this step added

U-1673 (S7.8: host.cpp dropped LiveTerrain's lines through a const_cast on log()). S3.10b's 10b_live made the log lazy (a compact record
per call, the lines formatted only when log() is read) with log_size() / drop_log(); S7.8's 8_merge.md section 3 asked for
set_keep_log / calls(). Both are in: LiveTerrain::set_keep_log(false) records no call at all, calls() counts every call either way and
places the snapshots (keep_snapshots used log_.size(), equal to calls() whenever every line is kept and none dropped: the tests' case).
host.cpp TerrainLogBound::frame_end counts log_size(), drops the boot's first-frame lines with drop_log() and then calls
set_keep_log(false); calls() = LiveTerrain::calls(); length() = log_size(). The const_cast is gone. The negctl `terrain-log-keep` (keep =
true) still keeps every line (test_app_present's control: terrain_log_end == terrain_calls).

Controls added (all RED):
- GlRaster `#workerctl 1` (GlRaster::worker_ctl): the last of several workers flips bit 0 of the first pixel it writes in each row of a
  triangle; with one thread it has no effect, so it reads only the worker path. 12_frames.py `--line "#threads 4\n#workerctl 1"`: 270 of
  299 recorded passes differ from the old rasteriser in frame SHA-1 (12_out/S3_12/g_frames_ctl.log); 12_equiv.py mode `workerctl`.
- gfx.family.terrain mode 6 (terrain_live.cpp): set_keep_log(false) from the first call in a run that reads the log; mode 7: the compact
  record drops setType's variation, so the lazy line has no `var=`. log/roadmap/S3/12_ctl_live.py (TL.run, the comparison of
  test_terrain_live.test_calls_equal_the_original): sandbox_basic and cov_k1_terrain mode 0 calls equal (25,405 / 26,017 calls), mode 6
  0 port calls (RED), mode 7 first difference at call 4 `setType T2499 0x14 ... var=0` (RED) (12_ctl_live.log).
- S3.10b's terrain_state control 23 (the view's byte stores dropped) and S3.10's `#fastpath 3` / `#fastpath 4` run in test_terrain_state
  / test_gl_raster / 12_equiv.py as before.
