## Method

1. The converter `re/tools/snd_hook2port.py --step S4.3` (through 3_convert.py) refused 22 of 42 blocks (it cannot parse the hooks' nested
   `static_cast<double>` expressions) and its output for the rest used host pointers. Instead, `3_xlat.py` carries every detour over mechanically
   into a virtual-pointer layer that keeps the hook's expressions verbatim: a hook's `float* p` becomes `P<float> p`, `p[i]` an R<float> that loads
   on read and stores on write, so each `fstp dword` spill the hook writes as a float assignment stays one. The hooks are the C3 bodies (GREEN at C3,
   C4 by match), written with the c3ap method at word 0x027f.
2. Hand edits (body.cpp): every local the original passes by address moved into the original's frame at its ebp offset (codecDecodeParams' three
   decodeTableSymbol cells and the intPow exponent, quantizeParams' exponent, codecAlignAnalysisWindow's q, codecRefinePitchLag's cand / subScores /
   count / out cells, codecWindowFeatures' scratch) and every frame array the hooks modelled as a host array (codecSynthesizeFrame's slot arrays,
   bitPermute's work slots, lpcSynthesize's local, reflectionToLpc's aliased work array, interpSubframeParams' frame, codecLdlSolveClamped's matrix)
   too, so overruns reach the same neighbours (U-1420, U-1423); integer divisions by a variable through div32 (DivideError instead of a host fault),
   intPow through mul32 / neg32; CRT sqrt / floor inline; codec globals 0xb58a0 / 0xb58a4 / 0xb58a8 through SoundState (g_codecOrder,
   g_codecFrameLen, g_codecErrProtect).
3. Calls between codec functions go through the dispatcher (ccall by rva), so the registry's port function or a fixture claim runs.
4. Stack locals: ONE helper, CodecFrame (U-1420). No image cell band: S4.8's SndLocals frame block (0xFEB00000, grows down).
5. x87: all keys at 0x027f; doubles + float spills are exact on x64 and Win32 (U-1421 for other caller words). log / exp: U-1422.

## Findings (the original; from the hooks' notes and this step, nothing changed)

- intPow divides 1 by a zero base for exponents below 0 (#DE at rva 0x3e313); no game input reaches it in the keys.
- codecRefinePitchLag's inner codecAmdfPitch out cell `subBest` is slot 0 of the score array it then indexes ([ebp-0x2c]): a returned index of 0
  reads the index itself as a float.
- reflectionToLpc's work array aliases its two loop slots from an order of 12 (c3bn's note, reproduced in the frame).
