step's files plus exactly these edits). Until they are applied, `port/test/test_static.py::test_every_module_file_is_listed`

## 3. port/src/portsim_c.cpp

a. After `#include <cstring>` add `#include <cstddef>`; after `#include "portsim/sim/tick.h"` add
   `#include "portsim/sim/audio.h"`.

b. Replace `void sg_state_free(sg_ctx *ctx) { delete ctx; }` by

```cpp
void sg_state_free(sg_ctx *ctx) {
  if (ctx) portsim::audio_release(ctx->ctx);  // S4.2: the audio core's per-context state
  delete ctx;
}
```

   (the audio core keeps per-context state in a side table keyed by the Ctx address, like commands.cpp's providers; without
   this a new context allocated at a freed one's address would inherit its host and claims.)

c. Insert the block of `log/roadmap/S4/2_cabi.cpp.txt` verbatim immediately before the file's last line `}  // extern "C"`
   (static_asserts of the layout against portsim::SndCallC and the definition of sg_snd_set_host).

The Win32 runner (port/test/runner32) needs NO change: the replay's Win32 path configures the core through sg_call entries
`audio_core.*` and context files `$audio/...`, and serves host calls from the in-library script host. A live callback across
the runner's pipe is not needed for any gate.
