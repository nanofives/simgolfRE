1. The interface (commands.h, given to 3.7a through the parent within the first half hour, then extended twice)
   - Command{kind, handler, a0, a1, async_ctrl, async_shift, t, arg[8]}. RAW kind RootHandler = one root-window handler
     call exactly as a trace HANDLER record gives it (handler id 1..11, two stack arguments), plus the GetAsyncKeyState
     results the press handlers read (KEYSTATE) and the clock value the deadline tail compares (the handler's own CLOCKRUN).
     apply_command performs that handler's writes: g_rootInput, gDirtyFlagA / B, g_char83821c, g_key838208, g_ui83ab9c.
   - SEMANTIC kinds 0x100..0x106 = one ported click handler's action with its hit test decided (arg[0] = the hit test's
     value); test_semantic_command_equals_the_click shows each equals the click at a point with that hit result.
   - tickFrame applies the frame's own raw commands at H1 (apply_commands) and attaches the rest as an InputSource. Every
     pump inside a straddler asks the source for ONE batch (one original dispatch call) with a PumpKind: Blocking (a loop
     that only ends on input: pumpAndRedraw(0), the screens' click-or-key loops; none left -> NeedInput, a MissingResource
     -> SG_E_NO_RESOURCE) or Drain (pumpLight, interruptible waitTicks: returns at once when nothing has arrived). A
     clockless port cannot tell what "has arrived" at a drain, so the source carries the timing (U-0940). QueueInput
     (tests): Blocking takes every command up to and including the first press or key, Drain takes nothing. The source
     also answers cursor reads (View_toLocal) for the screens whose effect depends on the cursor (U-0943).
   - Messages to the parent: the header (twice), composeGolferSprite's sim write from drawing (drawQueuedSprite in P4),
     g_value587ea0 / appendDate / showInfoCursorPanel's esi write, and g_textBuf (a hashed sim object that is only
     appendNumber / appendCents formatting scratch, written by drawing paths every frame; U-0944).

2. Method
   - No corpus vectors exist for any of the 62 (re/port/vectors_manifest.tsv: every key excluded). The evidence is an
     EMULATOR ORACLE (cmdemu.py, opt-in SG_EMU_ORACLE=1): the ORIGINAL function runs in Unicorn from the user's file image
     over constructed GameState images; the callees the port drops are stubbed with their own convention (from their
     `ret N`); frameTick483cd0 (the dispatch point) runs the ORIGINAL root handlers on the next scripted batch through a
     trampoline, with GetAsyncKeyState / timeGetTime answered from the command; a pumpMessages whose caller is pumpLight
     or waitTicks (the return address at [esp + 0x20] on entry) is a Drain and gets nothing; View_toLocal returns the
     scripted cursor. eax, consumed input and the whole data image must equal the port's (layout and screen functions
     mask only the drawing scratch the port does not reproduce: g_textBuffer, the hover counters g_panelState[1] /
     g_ui_5aa554, the sprite cell g_ui_5aa6b8[3], g_value587ea0, the itoa buffers g_panelNumberText / g_ui_821c50 /
     g_infoPanelNumBuf, appendCents' g_ui_569628). Branch coverage per jcc side is measured on the same cases
     (log/p3/p37b/cover.py). Peers of other children are run for real on both sides, except buildGolferComment in
     showPlayerCommentsReport, whose calls are recorded on both sides (commands.recordPeer) and compared as sequences
     (U-0945).
   - The default suite runs no original code: GOLDEN digests (port/test/golden_commands.json, 60 fixed cases per
     function: eax, error, consumed input, whole image) pinned from the port only after the oracle was GREEN on them
     (SG_EMU_ORACLE=update), plus every negative control against those digests (and against the original with the oracle).
   - The 62 were classified by a write audit (log/p3/p37b/audit.py: every data address each body writes, its object and
     class, and every function that reads it): a write that a click handler, mainLoop or a simulation function reads is
     an effect even when it sits in a drawing function (drawAmenitiesPanel's g_panelState[0], drawEmployeeViewPanel's
     list, drawEmployeeDetailPanel's list / zoom / walker animation word / hire trigger, appendDate's g_year).
   - Built in a private mirror (log/p3/p37b/mirror.py: port/ at HEAD for every file a sibling modified, plus this child's
     new files; 3.7a's tick* excluded while it did not compile) at port/build/m37b, each build copied to
     port/build/m37b_run so a running test never locks the next build.

   - showHireEmployeeDialog's sprite frame counter is divided by the sheet sizes even when nothing is drawn (#DE on 0).
   - hitTestSlot432f90 reads the palette sprites' height field (g_sprites570cb8 +0x1c, a pointer-class object): the
     toolbar's hit boxes depend on the loaded art.

6. Lessons
   - Unicorn caches translated blocks: rewriting code at one address runs the old translation (a fresh trampoline slot per
     dispatch, ctl_remove_cache when the slots wrap).
   - test_static refuses every 6-8 digit literal in the image ranges, comments included: write flag masks as shifts and
     cite functions by name in port code (addresses stay in notes and the split table).
   - A sibling's in-flight edit of a shared file (events_calls.inc lost its startMessage copy) breaks other modules' tests:
     a private mirror at HEAD + own files keeps the baseline stable.
