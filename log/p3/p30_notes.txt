Method
- Each function written from its analysis note's Purpose and the disassembly (capstone over original/golf_clean.exe,
  re-read for every operand width, signedness and argument order: direction8's esi = first argument, angleFixed's
  ebp = first argument / ebx = -second, objectAt's ebp = x / ebx = y, inRange's dist = second argument, tileDistance's
  pushes). Matched sources (re/match) and hook sources (shim/src/re) read for cross-checking only; no literal address
  in port code (test_static.py).
- appendClubName's 14 string offsets in f_strpool_4c4f98 (0x218..0x288) come from its jump table 0x0040aa44 (each case
  `mov edi, <pool address>`); the strings stay in the exe / corpus.
- inRange: the window for types other than 0x15 / 0x16 is hi = lo = type (0x004070ed / 0x004070f1: both registers load
  the type argument), so v < type && v > type is always false; the match source's comment calls these uninitialised.
- initSinTable: g_sinTable[i] = __ftol(sin(i * k1) * k0), k0 = 65535.0 and k1 = 0.006159985596078431 (the two doubles of
  f_k_dbl_4bba48, read through ExeConstants). The CRT sin reproduces all 256 entries of the table in every segment start
  image (190 images, one distinct table); the dword after the table is 0 in all of them (model_defects#10).
  Its trailing calls sinScaled(0x40000000, 100) / cosScaled(0xa02d82d8, 100) discard their results; both are pure.
